## 4. メニュー・担当・施術時間

**2026-10-07 直した**（tests/test_line_menu_real_db.py の7件。修正前に6件が失敗することを確認）。
- 届いた文字に院のメニュー名があれば、それがメニュー（AIの読み取りより先にコードで見る。長い名前を優先＝「保険延長」を「保険診療」と読まない）。解析AIにも院のメニュー名の一覧を渡す。院に無いメニュー名の固定の表は、一覧が分かっているときは使わない（C3）
- スタッフが「いつもの」を登録しているリピーターには、日時だけ言われたら先に「いつもの◯◯（担当: ◯◯）でよろしいでしょうか」を聞く。言われた日時は覚えておき、「はい」の後にその日の候補へ進む。本人がメニューを言った・「いつもの」を押した・一度「はい」と答えた後は聞かない（C2）
- **メニューのボタンは「⭐️いつもの」だけ、施術時間はボタンにしない**（正解 D7・まことさん 2026-10-07）。以前（2026-04 から）は「⭐️いつもの」＋メニューを並び順に最大6つ出していた（ホットペッパー等も出る）。いったん3つまでに減らしたが、ボタンは候補と、はい／いいえだけ、の決定に合わせて外した。「いつもの」が無い人にはボタンを出さず、LINEへは普通の文として送る（空のボタン一覧は LINE が受け付けないので、送る側で普通の文に切り替える）
- 自動で予約してよい施術時間の下限を20分に（既定値と、本番の設定が既定の30のままなら20へ直すマイグレーション 031）（X6）

まことさんの確認（2026-10-07）：C2 はスタッフ登録の「いつもの」がある人だけ → OK（正解 C6）。メニュー・施術時間のボタン → 出さない（上のとおり）
